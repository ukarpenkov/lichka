# Debug-сид демо-данных для скриншотов Google Play

**Дата:** 2026-08-26  
**Статус:** in progress (debug seed на устройстве)  
**Ветка для реализации:** `chore/play-store-demo-seed` (не мержить в `main`)  
**Цель:** на физическом Android по USB получить правдоподобные чаты, прошлые сообщения и запланированные события — для скриншотов в Google Play.

## Контекст

Схема-миграции уже есть (`runMigrations()`). При старте только `seedDefaultChat()` — пустой системный «Saved». Отдельного демо-сида нет. Класть фейковые данные в SQL-миграции нельзя: они приедут всем пользователям.

## Что сделать

- [x] Ответвиться от `main` в `chore/play-store-demo-seed`
- [x] Поставить debug на телефон: USB-отладка → `adb devices` → `yarn android`
- [x] Debug-only сид (не новая схема-миграция): несколько чатов, сообщения с датами в прошлом, reminder/alarm/periodic с `scheduled_at` в будущем
- [x] Тексты и состав данных под стор: список чатов, лента истории, Future Peek, вкладка Scheduled
- [x] Запуск сида только в `__DEV__`, один раз (флаг в БД/settings). На этой ветке первый запуск **replace** существующих чатов (для скринов); повторно не сидит
- [ ] Снять скриншоты на устройстве (светлая/тёмная при необходимости), без debug-оверлеев Metro
- [ ] Ветку **не** мержить в `main`; AAB в Play — с `main` без этого сида

## Ограничения

- Не трогать `src/shared/db/migrations/*.sql`
- Не менять поведение `seedDefaultChat()` в проде
- Не коммитить секреты, реальные чаты, фото с телефона в репозиторий
- Коммит в demo-ветке — только по явной просьбе

## Проверка

1. Чистая debug-установка по USB.
2. После сида: список чатов не пустой; в чате видны прошлые даты; Future Peek и Scheduled показывают будущие события.
3. Release / `__DEV__ === false`: сид не выполняется.
