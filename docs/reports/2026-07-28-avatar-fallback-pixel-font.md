# Шрифт буквы-заглушки в аватаре чата

**Дата:** 2026-07-28
**Промпт/задача:** Изменить шрифт буквы в аватаре чата (при отсутствии фото/иконки) на пиксельный шрифт приложения; при возможности сжать написание на 15%.

## Что сделано
- Буква-заглушка в `Avatar` рендерится пиксельным display-шрифтом Press Start 2P (`fonts.display`)
- Горизонтальное сжатие глифа на ~15% через `transform: [{ scaleX: 0.85 }]`
- Обновлён unit-тест: проверяет `fontFamily` и `scaleX`

## Изменённые файлы
- `src/shared/ui/Avatar.tsx` — fallback-рендер буквы: pixel font + scaleX
- `src/shared/ui/__tests__/Avatar.test.tsx` — сценарий для начальной буквы; mock `config` через `requireActual`

## Принятые решения
- Использован уже подключённый `fonts.display` (Press Start 2P), как в заголовках и будильнике
- Сжатие через `scaleX: 0.85`, а не уменьшение `fontSize` — сохраняется высота, сужается только ширина (шрифт изначально широкий)

## Известные ограничения
- `scaleX` — визуальное сжатие, не метрика шрифта; на очень маленьких аватарах эффект может быть едва заметным

## Тестирование
- `npx jest src/shared/ui/__tests__/Avatar.test.tsx` — 3 passed
  - themed pixel icon
  - legacy emoji
  - title initial в pixel display font со `scaleX: 0.85`
