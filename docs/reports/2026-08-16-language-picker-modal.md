# Выбор языка через модальное окно в настройках

**Дата:** 2026-08-16
**Промпт/задача:** Выбор языков в настройках смещает текст пункта меню. Сделать так, чтобы выбранный язык отображался коротким написанием, а при нажатии открывалось модальное окно (как при удалении чата) с кнопками полных названий языков.

## Что сделано
- В строке «Язык интерфейса» в настройках вместо шести пилюль-переключателей теперь отображается только короткий код текущего языка (RU, EN, ...) и стрелка-шеврон.
- По нажатию на строку открывается `AlertDialog` (тот же компонент, что и подтверждение удаления чата) с заголовком «Язык интерфейса», кнопкой «Отмена» и кнопками для каждого языка с полным названием на его родном языке («Русский», «English», «Español», «Deutsch», «Français», «Português»).
- Текущий выбранный язык помечен префиксом «✓».
- В каждый локаль-бандл добавлено поле `nativeName` — полное название языка на его родном языке.

## Изменённые файлы
- `src/pages/settings/SettingsScreen.tsx` — удалены inline-пилюли выбора языка и связанные стили (`localeToggle`, `localePill`, `localeLabel`); строка языка стала кликабельной (`SettingsRow` с `onPress`), показывает короткий код через `locale.toUpperCase()` и открывает `AlertDialog` со списком языков; удалены неиспользуемые импорты (`Pressable`, `monoWeight`, `radii`).
- `src/shared/config/locale/types.ts` — в интерфейс `LocaleBundle` добавлено поле `nativeName: string`.
- `src/shared/config/locale/ru.ts`, `en.ts`, `es.ts`, `de.ts`, `fr.ts`, `pt.ts` — добавлены значения `nativeName`.
- `src/shared/config/__tests__/locale.test.ts` — добавлен тест на наличие непустого `nativeName` в каждом бандле.

## Принятые решения
- Полные названия языков хранятся в бандлах локалей (`nativeName`), а не в коде экрана — источник истины остаётся в конфиге локалей, добавление нового языка не требует правок UI.
- Отметка выбранного языка сделана текстовым префиксом «✓», так как `AlertButton` поддерживает только текстовые кнопки.
- Выбранный язык для отображения берётся из контекста `useLocale().locale`, а не из `settings` — не зависит от загрузки настроек.

## Известные ограничения
- Список из 7 кнопок (6 языков + «Отмена») отображается в одну колонку — высота модального окна больше обычного, но вписывается в экран.
