# Списки с галочками в сообщениях

**Дата:** 2026-10-13
**Промпт/задача:** добавить превращение многострочного сообщения в список через пиксельную кнопку слева от скрепки; разрешить отметки только после отправки, сохранять пункты и их состояние. Сначала написать proposal, затем реализацию и отчёт. Без коммита.

## Что сделано
- После Enter в поле сообщения появляется пустой пиксельный чекбокс слева от скрепки.
- Нажатие включает режим списка: кнопка получает галочку, перед каждой логической строкой появляются пустые квадраты. Повторное нажатие возвращает обычный текст без его потери.
- Сохраняется одно нативное поле ввода с существующим ретро-курсором: работают выделение, вставка и многострочный ввод. Маркеры декоративные, не нажимаются и прокручиваются вместе с текстом.
- После отправки пункт переключается нажатием: галочка, зачёркнутый текст и обратное снятие отметки. Долгое нажатие сохраняет меню сообщения.
- Пункты имеют стабильные идентификаторы, текст и собственное состояние `checked`; изменения сразу записываются в SQLite. При повторном чтении чата состояние восстанавливается.
- Добавлена миграция 9: nullable-колонка `messages.checklist` для JSON-массива пунктов. Обычные сообщения сохраняются с `NULL`.
- Список совместим с изображениями и напоминаниями; у периодического напоминания состояние хранится в шаблоне и сохраняется при его завершении.
- При редактировании неизменённые пункты сохраняют галочки, в том числе при перестановке. Новые и переименованные пункты начинаются без отметки. Одинаковые пункты остаются независимыми.
- Поиск, копирование, превью и уведомления продолжают использовать обычный текст `body`.
- Экспорт JSON/ZIP сохраняет пункты и галочки. Формат обновлён до версии 3; импорт читает версии 1–3, проверяет структуру пунктов и не затирает более новые локальные данные при объединении.
- Добавлены подписи доступности и сообщение об ошибке сохранения для всех шести языков.
- Коммит агентом не создавался.

## Принятые решения
- Признак списка — наличие массива в новом поле `checklist`; отдельный тип сообщения не вводится, чтобы список можно было совмещать с напоминанием или изображением.
- Форма галочки взята из `business-product-check` набора Streamline Pixel (CC BY 4.0); декоративный контур исходной иконки заменён квадратной рамкой на той же сетке 32×32. Уже используемые иконки не менялись.
- До отправки виден маркер у каждой строки, включая текущую пустую. При отправке пустые строки и конечный Enter отбрасываются; автоматический перенос длинного текста не создаёт дополнительных пунктов.
- Галочки сопоставляются по неизменённому тексту; дубликаты сопоставляются по порядку. Переименованный пункт считается новой задачей.
- Версия резервной копии увеличена, чтобы старое приложение не приняло файл с неподдерживаемыми данными и не потеряло галочки молча. Отдельный механизм бэкапа не добавлялся.

## Известные ограничения
- Android-устройство или эмулятор не подключены. Нативное отображение при переносе длинных строк, крупном системном шрифте и прокрутке требует ручного просмотра на устройстве; автоматические тесты не заменяют эту проверку.
- Неотправленный черновик остаётся в памяти, как и раньше. Постоянное хранение введено для отправленных списков и галочек.
- У периодического напоминания список общий для шаблона: автоматического сброса галочек при очередном срабатывании нет.
- После изменения галочки обновляется `updatedAt`; существующий индикатор редактирования сообщения также может появиться.
- APK/AAB не собирался, номер релизной версии не менялся.

### Покрытые сценарии
- Кнопка скрыта при обычном вводе и появляется после явного Enter.
- Включение/выключение списка сохраняет текст; до отправки пункты недоступны для отметки.
- Отправка примера «молоко, кефир, Coca-Cola, сода» создаёт четыре невыполненных пункта и очищает режим.
- Обычное многострочное сообщение не превращается в список автоматически.
- Пустые строки, CRLF, добавление новых строк, очистка черновика, длинная логическая строка и прокрутка декоративных маркеров.
- Галочка, зачёркивание, повторное нажатие, доступность и долгое нажатие для меню.
- Хранение и повторное чтение, удалённое сообщение/пункт, ошибка записи.
- Редактирование, перестановка, дубликаты, удаление всех строк, завершение периодического напоминания.
- Экспорт пунктов, импорт replace/merge, сохранение более нового локального состояния и откат повреждённых списков.
