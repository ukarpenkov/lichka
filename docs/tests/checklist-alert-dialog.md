# Проверка: neo-brutal AlertDialog

- [ ] **Удалить сообщение** — попап с 2px border + hard offset shadow цветом темы (не soft blur)
- [ ] **Удалить чат** — то же самое, кнопки как neo-brutal chips (border + hard shadow)
- [ ] **Тёмная тема** — фон диалога тёмный, текст светлый, тень/бордер цветом `text`
- [ ] **Светлая тема** — переключить тему, диалог светлый, hard shadow читаема
- [ ] **Цветной пресет** (например green-on-black) — текст и кнопки читаемы
- [ ] **Анимация** — окно плавно появляется (fade + zoom), без смены spring-параметров
- [ ] **Кнопка Cancel** — muted текст, закрывает диалог без действия
- [ ] **Кнопка Delete** — destructive (красный текст/бордер), выполняет удаление, диалог закрывается
- [ ] **Press кнопок** — смещение ~3px + скрытие hard shadow
- [ ] **Тап вне окна** — диалог закрывается
- [ ] **Настройки → импорт/restore (≥3 кнопки)** — кнопки в **вертикальном столбце**
- [ ] **Настройки → nested replace confirm** — второй диалог открывается после первого (timing ~300ms)
- [ ] **Настройки → экспорт/ошибки** — success/error dialogs в том же neo-brutal стиле
