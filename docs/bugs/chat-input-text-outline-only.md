# Баг: текст в поле ввода чата полупрозрачный, видны только контуры

**Дата:** 2026-08-28  
**Платформа:** Android / iOS (воспроизведено в композере сообщения, тема Green on Black)  
**Регрессия после:** горизонтальный ретро-курсор (`docs/features/retro-horizontal-text-caret-proposal.md`, 2026-08-27)

## Описание

После последних обновлений в поле ввода сообщения текст набирается, но почти не читается: заливка символов пропадает, остаются тусклые полупрозрачные контуры. Приглашение `>` и иконки композера при этом рисуются обычным непрозрачным `colors.ink`.

## Компонент

`MessageComposer` → `RetroTextInput` (`features/retro-text-caret`)

## Шаги воспроизведения

1. Открыть чат (удобнее на тёмной теме, например Green on Black).
2. Сфокусировать поле ввода сообщения.
3. Набрать текст (кириллица или латиница).

## Ожидаемый результат

Набранный текст сплошной, того же цвета и непрозрачности, что приглашение `>` (`colors.ink`).

## Фактический результат

Текст в инпуте — тёмные/оливковые полупрозрачные контуры на фоне canvas. Сообщение при отправке сохраняется корректно: ломается только отрисовка во время ввода.

## Локализация

- `src/features/retro-text-caret/RetroTextInput.tsx` — измерительный `Text` поверх `TextInput` со стилем `color: 'transparent'`
- `src/widgets/message-composer/MessageComposer.tsx` — композер подключает `RetroTextInput`

## Причина

Чтобы поставить горизонтальный caret, `RetroTextInput` кладёт над нативным полем скрытый `Text` с тем же префиксом и слушает `onTextLayout`. Скрытие сделано через `color: 'transparent'` (`#00000000`).

На мобильных рендерерах это не делает глифы невидимыми:

1. Прозрачная заливка всё равно растеризуется: антиалиасинг даёт видимые контуры.
2. Слой лежит в `absoluteFill` поверх `TextInput` в момент фокуса. Платформа может не просвечивать залитый текст поля сквозь этот слой (opaque text view / occlusion), поэтому пользователь видит только контуры измерения, а не `colors.ink` инпута.

Иконки и `>` не затронуты: они вне `RetroTextInput`.

## Исправление

Скрывать измерительный слой через `opacity: 0`, а не через прозрачный цвет. `onTextLayout` при этом срабатывает, контуры не рисуются, набранный текст в `TextInput` остаётся непрозрачным.
