# Баг: Текст поиска и иконка закрытия не на одной горизонтали

## Описание
В оверлее глобального поиска (и аналогично в поиске внутри чата) placeholder/текст в поле ввода и иконка закрытия (X) не лежат на одной горизонтальной линии по центру. Текст визуально смещён вверх относительно крестика.

## Компонент
- `GlobalSearch` → `TextInput` + `IconButton` (X)
- `SearchOverlay` → тот же паттерн

## Шаги воспроизведения
1. Открыть список чатов
2. Открыть глобальный поиск («Поиск по сообщениям...»)
3. Сравнить вертикальный центр placeholder и иконки закрытия справа

## Ожидаемый результат
Текст (placeholder) и иконка X центрированы по одной горизонтальной оси относительно высоты поля ввода.

## Фактический результат
Placeholder смещён вверх внутри серого поля; крестик визуально ниже центра текста (или они не совпадают по центру).

## Локализация
- `src/pages/chat-list/GlobalSearch.tsx` — `styles.input` (`lineHeight: 20`, фиксированная `height: 40`)
- `src/pages/chat-room/SearchOverlay.tsx` — тот же стиль input

## Причина
У однострочного `TextInput` с фиксированной высотой был задан `lineHeight: 20` при `fontSize: 16`. На iOS/Android это сдвигает текст/placeholder по вертикали внутри контрола. Ряд (`inputRow`) уже имел `alignItems: 'center'`, и `IconButton` центрировался относительно контейнера поля — расхождение давал именно внутренний сдвиг глифа текста, а не рассинхрон flex-ряда.

## Исправление
В обоих экранах поиска:
- убрать `lineHeight` у `TextInput`;
- добавить `paddingVertical: 0`;
- задать `textAlignVertical="center"`;
- на Android — `includeFontPadding: false`.
