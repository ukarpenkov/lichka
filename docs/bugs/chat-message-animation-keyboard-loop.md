# [UI] Бесконечное колебание / мерцание ленты чата (в т.ч. после перезапуска)

**Дата обнаружения:** 2026-08-12  
**Статус:** in progress (2026-08-12, inverted list)  
**Платформа:** Android (скорее всего), любой чат с высотой контента ≈ высоте viewport

## Описание

Список сообщений дёргался / мерцал, затем последние сообщения обрезались. Клавиатура, Future peek и перезапуск только проявляли симптом.

## Почему чинили не то

Лента была **не inverted**. Последнее сообщение держали у композера через `scrollToEnd` после каждого изменения layout. Это типично ломается:

- клавиатура меняет высоту viewport;
- свайп в Future **размонтирует** историю, обратно список встаёт на offset 0 (верх хронологии);
- `flexGrow` / `scrollEnabled` вокруг порога «влезает ли лента» меняли высоту контента.

В июне `inverted` сняли, потому что данные шли ASC без reverse — новые сообщения оказались сверху. Вместо reverse+inverted оставили ASC и начали догонять низ скроллом. С тех пор каждый экран/клавиатура — новый хак.

## Настоящее исправление

История — **inverted FlatList**: данные с date-separators реверсятся, index 0 = последнее сообщение = визуальный низ = зазор `MESSAGE_LIST_BOTTOM_GAP` над композером.

Offset 0 после remount / клавиатуры / Future **и есть** хвост у ввода. `scrollToEnd` для пина больше не нужен.

`flexGrow` + inverted на Android оставлял leftover над композером. Убран flexGrow; хвост держится нативным inverted + `scrollToOffset(0)` при keyboard/layout. `FadeOutDown` на строках убраны.

## Проверка

1. Короткий и длинный чат: последнее сообщение с небольшим зазором над композером.
2. Open/close клавиатуры — одинаковый маленький зазор, без анимации ленты.
3. Свайп Future → обратно — хвост на месте.
4. Kill app → тот же чат — спокойная лента, хвост виден.
5. Скролл к старым сообщениям при открытой клавиатуре (Android) жив.
6. Новое сообщение: появляется снизу; enter-анимация не запускается по всему списку при клавиатуре.
