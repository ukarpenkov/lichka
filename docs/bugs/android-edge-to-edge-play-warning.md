# Предупреждение Google Play об отображении от края до края

Для выпуска 11 (3.1) Play Console сообщает об использовании неподдерживаемых API или параметров edge-to-edge при target SDK 36.

Причина: поддержка edge-to-edge в React Native была выключена свойством `edgeToEdgeEnabled=false`. Кроме того, приложение задавало цвет строки состояния через устаревший при Android 15+ API.

Исправление: включить режим React Native, оставить настройку цвета значков системной панели и учитывать системные отступы в отдельном экране будильника. После сборки проверить отображение на Android 15/16 с жестовой и трёхкнопочной навигацией, включая просмотр изображения и будильник. Окончательное исчезновение предупреждения подтверждается только новым анализом Play Console.
