# Клавиатура перекрывает формы и панель сообщений

**Дата:** 2026-10-17
**Статус:** исправлено в коде; проверено на эмуляторе, ожидается проверка на физических устройствах

## Проявления
- При создании чата клавиатура закрывает имя, аватар и кнопку создания. По сообщению пользователя воспроизводится на всех устройствах (001.jpg).
- На Realme (точная модель не установлена: возможно GT 7T) клавиатура перекрывает кнопки отправки, напоминания и будильника (002.jpg). На Pixel и Xiaomi пользователь этого не наблюдает.

## Причины и область проверки
- ChatForm использует Android Modal и не включает KeyboardAvoidingView на Android. Полагаться только на автоматическое изменение размера окна недостаточно.
- Чат вычисляет компенсацию как высота события Keyboard минус предполагаемая высота tab bar. В установленном RN 0.85.3 событие вычитает системную панель из IME insets и отправляется только при смене видимости, а не при изменении размера открытой клавиатуры.
- Аналогичные риски: редактор сообщения, ввод периода, списки результатов поиска.
- При проверке на эмуляторе найдено дополнительное перекрытие поля поиска внутри чата: header имеет zIndex/elevation 30, а поиск — zIndex 20. Поиск поднят выше header (zIndex/elevation 40).

## Исправление
Измерять фактическое перекрытие Android-клавиатуры и контейнера в координатах одного окна через WindowInsetsCompat; учитывать уже выполненный resize и не компенсировать его повторно. Сохранить layout-spacer чата и стабильность дерева списка/ввода. Добавить прокрутку длинных форм.

## Проверка
Пройдены 669 Jest-тестов, 8 Android-тестов, TypeScript, ESLint изменённых файлов и debug-сборка. На эмуляторе Small_Phone (720×1280, API 37) проверены создание чата, отправка, изменение высоты Gboard, ввод периода цифровой клавиатурой, жестовая и трёхкнопочная навигация.

Остаётся ручная матрица на Pixel, Xiaomi, Realme/OPPO/OnePlus: обе навигации, высокая клавиатура, поворот, повторное открытие форм, редактирование, поиск, отправка и планирование. Физические устройства не подключены, межбрендовая проверка не подтверждена. Точная модель и версия Android исходного Realme неизвестны.
