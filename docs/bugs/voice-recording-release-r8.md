# Диктофон не запускается в релизе при разрешённом микрофоне

**Статус:** исправлено; оптимизированный код проверен, проверка на устройстве ожидается

## Симптомы

После выдачи разрешения на микрофон появляется сообщение «Could not start recording. Check microphone access and try again.».

## Причина

В Android release включён R8 (`minifyEnabled true`). Библиотека `react-native-audio-recorder-player` 4.5.0 создаёт `HybridAudioRecorderPlayer` из C++ по строковому имени через `DefaultConstructableObject`. На реализации класса нет `@Keep`, а библиотека не поставляет соответствующее consumer-правило.

R8 не видит этот вызов и удаляет реализацию диктофона. В существовавшем `android/app/build/outputs/mapping/release/usage.txt` класс `com.margelo.nitro.audiorecorderplayer.HybridAudioRecorderPlayer` указан целиком среди удалённых; в `mapping.txt` его нет. Сохранившийся `HybridAudioRecorderPlayerSpec` — только абстрактный базовый класс и не заменяет реализацию.

Проверка разрешения в `MessageComposer` проходит, но создание аудиомодуля завершается ошибкой. Текст общего сбоя ошибочно снова отправляет пользователя проверять доступ к микрофону. Тот же аудиомодуль используется для воспроизведения голосовых сообщений.

## Исправление

- Добавлено точечное правило R8, сохраняющее имя, конструктор и методы `HybridAudioRecorderPlayer`.
- Убрано предположение о запрете микрофона из общего сообщения об ошибке во всех локализациях. Для отказа в разрешении уже есть отдельный диалог.
- Слои FSD и API записи не меняются.

## Проверка

- `:app:minifyReleaseWithR8 --offline --console=plain` — успешно. В новом `mapping.txt` класс, конструктор и методы записи/воспроизведения сохранены под исходными именами; класс отсутствует среди удалённых в `usage.txt`.
- Через Android SDK `dexdump` подтверждено: в ранее собранном release APK реализации диктофона нет; в новом оптимизированном `classes.dex` есть класс и конструктор без аргументов, который вызывает Nitro.
- Jest: `requestMicrophonePermission.test.ts` и `MessageComposer.test.tsx` — 23 теста прошли, включая уже выданное разрешение, успешный запуск, отказ в разрешении и ошибку запуска.
- ESLint изменённых локализаций и `git diff --check` — без ошибок.
- Устройство не подключено (`adb devices -l` не вернул устройств). Остаётся проверка на телефоне с новой релизной сборкой: разрешить микрофон, записать сообщение и воспроизвести его.

Для проверки R8 не требуется собирать AAB/APK. Перед следующей сборкой для Google Play необходимо увеличить `versionCode` согласно `AGENTS.md`; ранее собранные артефакты исправление не содержат.
