# Текст отложенных сообщений обрезается на экране Future

## Проблема

На экране Future длинные и многострочные сообщения отображаются только в одну строку с многоточием. Чтобы прочитать напоминание целиком, приходится открывать его отдельно.

## Причина

В `src/pages/chat-room/FutureTimeline.tsx` компоненту текста сообщения передаётся `numberOfLines={1}`.

## Исправление

Убрано ограничение количества строк. Каждое сообщение отображается целиком с сохранением переносов; высота строки списка увеличивается по содержимому.
