# [UI] Клавиатура самопроизвольно закрывается после фокуса поля сообщения

**Модуль:** `src/pages/chat-room/ChatRoomScreen.tsx`
**Платформа:** Android
**Приоритет:** P0
**Воспроизводимость:** 100%

## Описание

На экране чата при тапе по полю `Message...` клавиатура открывается, примерно через секунду закрывается без действия пользователя, а поле теряет фокус. Повторный тап запускает тот же цикл, поэтому ввести сообщение невозможно.

## Шаги воспроизведения

1. Открыть любой чат, например `Saved`.
2. Тапнуть по полю ввода `Message...`.
3. Не выполнять других действий.

## Фактический результат

Клавиатура открывается и почти сразу закрывается, поле ввода теряет фокус.

## Ожидаемый результат

Клавиатура и фокус сохраняются, пока пользователь сам не закроет клавиатуру, не покинет экран или не отправит сообщение.

## Корневая причина

Композер сообщений условно оборачивался в `GestureDetector` только при активном входном future-peek gesture (`atBottom === true`). Открытие клавиатуры меняет высоту списка и запускает перерасчёт `atBottom`. При смене значения React менял иерархию с `GestureDetector → View → MessageComposer` на `MessageComposer` или обратно.

Из-за изменения родительской иерархии `MessageComposer` размонтировался и создавался заново. Вместе с ним пересоздавался нативный `TextInput`, поэтому текущий фокус терялся и Android закрывал клавиатуру.

## Исправление

Иерархия композера сделана стабильной: native gesture boundary теперь присутствует всегда. Доступность внешнего future-peek pan по-прежнему управляется состоянием самого pan gesture, поэтому постоянная обёртка не активирует переход вне нижней границы списка.
