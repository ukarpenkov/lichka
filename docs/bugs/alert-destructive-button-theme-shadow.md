# Баг: у destructive-кнопок в AlertDialog подложка цвета темы, а не акцента кнопки

## Описание
В диалогах подтверждения (`AlertDialog`) кнопки с постоянным цветом (destructive, красный «Удалить») имели красные текст и обводку, но выступающая hard-shadow подложка оставалась цветом темы (на neon — зелёная). Визуально кнопка выглядела «разорванной»: лицо красное, тень зелёная.

## Компонент
- `AlertDialog` → `HardShadowButton`

Все похожие кнопки уведомлений/подтверждений идут через этот компонент (удаление чата, сообщения, расписания, импорт/замена в настройках и т.д.).

## Шаги воспроизведения
1. Открыть список чатов
2. Удалить чат → диалог «Удалить чат» / «Удалить «HOME»?»
3. Сравнить кнопку «Удалить» с кнопкой «Отмена»

## Ожидаемый результат
У кнопки с постоянным цветом (destructive) подложка совпадает с акцентом кнопки: красный текст, красная обводка и красная выступающая тень.

## Фактический результат
Текст и border красные (`colors.destructive`), подложка — `text` темы (зелёная на Green on Black).

## Причина
В `HardShadowButton` для destructive брался только `borderColor = colors.destructive`. Слой `hardShadowLayer` всегда заливался `shadowColor` (= `text` темы), который передавался из `AlertDialog` для всех кнопок одинаково.

## Исправление
Для destructive и `borderColor`, и `backgroundColor` подложки берутся из `colors.destructive` (`accentColor`). Cancel и default по-прежнему используют цвет темы.
