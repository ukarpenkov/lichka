# Виджет: убрать заголовок «Запланировано»

**Статус:** approved

## Название фичи

Убрать надпись «Запланировано» из Android home screen виджета.

## Описание проблемы

В виджете сверху всегда отображается заголовок «Запланировано» (TextView `widget_title`). Он дублирует имя виджета из пикера лаунчера и съедает вертикальное место, которое полезнее отдать списку задач — особенно на small-виджете (заголовок + 1 строка). Задача: оставить только список запланированных задач без заголовка.

## Предлагаемое решение

Удалить `TextView` `widget_title` из `res/layout/widget_scheduled.xml` и весь связанный код в `ScheduledWidgetProvider.kt`:

- `views.setTextColor(R.id.widget_title, inkColor)`
- `views.setTextViewText(R.id.widget_title, context.getString(R.string.widget_scheduled_title))`
- `views.setOnClickPendingIntent(R.id.widget_title, …)` (тап по заголовку → экран «Запланировано» остаётся доступен через `widget_root`)

Также убрать `layout_marginTop="8dp"` у `ListView` — отступ был нужен только как зазор между заголовком и списком.

### Что НЕ трогаем

- `@string/widget_scheduled_title` и ссылку на него в `AndroidManifest.xml` — это имя виджета в пикере лаунчера, оно остаётся.
- Пустое состояние `widget_empty` и его тап — остаются.
- Экран «Запланировано» в приложении (таб) — не меняется.

## Влияние на архитектуру

Только native Android слой (`res/layout/widget_scheduled.xml`, `ScheduledWidgetProvider.kt`). FSD-слои JS не затрагиваются, bridge и snapshot без изменений.

## Альтернативы

| Вариант | Почему не выбран |
|---------|------------------|
| Скрывать заголовок через `setViewVisibility` | Лишний RemoteViews-вызов; заголовок не нужен вовсе — проще удалить из layout |
| Оставить заголовок только на small | Несогласованность размеров, заголовок не несёт информации |

## Оценка сложности

Минимальная: удаление одного View и трёх вызовов в провайдере. Рисков нет (тап по пустой области уже покрыт `widget_root`).

## Тестирование

Пересобрать Android, обновить виджет: заголовок отсутствует, список начинается с верхнего отступа, тап по списку/пустому состоянию открывает «Запланировано».
