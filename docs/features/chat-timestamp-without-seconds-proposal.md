# Время сообщений без секунд в чате

**Статус:** implemented

## Название фичи

Сокращённый timestamp сообщения в ленте чата.

## Описание проблемы

Каждая строка сообщения начинается с времени в формате `[ЧЧ:ММ:СС]`. Секунды создают лишний визуальный шум и занимают место, хотя для просмотра истории чата достаточно точности до минуты.

При этом точное время сообщения должно по-прежнему храниться в приложении без потери секунд.

## Предлагаемое решение

Изменить только формат отображения timestamp в `MessageLine`: вместо `[ЧЧ:ММ:СС]` показывать `[ЧЧ:ММ]`.

Поля `createdAt` и `updatedAt`, формат ISO, БД, импорт, экспорт, сортировка и логика запланированных сообщений не меняются. Секунды остаются в данных приложения и убираются только из визуальной строки сообщения в чате.

Обновить тесты `MessageLine`, чтобы они проверяли формат без секунд и уменьшенную ширину колонки времени.

## Влияние на архитектуру

- `pages/chat-room` — меняется только представление строки сообщения.
- `entities/message` — без изменений: точные timestamps продолжают храниться как раньше.
- `shared` и остальные экраны — без изменений.

Зависимости FSD и публичные API не затрагиваются.

## Альтернативы

- Глобально изменить общий формат времени — не выбран, потому что это затронет другие экраны и нарушит требование убрать секунды только визуально в чате.
- Округлять или перезаписывать `createdAt` — не выбран, потому что приведёт к потере данных и может повлиять на сортировку сообщений.
- Скрывать секунды стилями — не выбран: явный форматтер проще, надёжнее и доступнее для тестирования.

## Оценка сложности

Низкая: изменение одного форматтера и связанных тестов. Основной риск — оставить лишнюю ширину колонки после сокращения timestamp.
