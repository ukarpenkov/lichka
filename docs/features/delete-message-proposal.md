# Удаление сообщения с побочными эффектами

**Статус:** implemented

## Название фичи

Единое удаление сообщения: база, уведомление и звук.

## Описание проблемы

Один и тот же сценарий удаления повторялся в комнате чата и на экране запланированных: удалить строку, отменить уведомление и проиграть звук, если он включён.

## Предлагаемое решение

Функция `deleteMessageWithEffects(id)` в слайсе `features/delete-message`. Экраны по-прежнему решают, когда показать диалог, какой id удалять и как обновить свой список.

## Влияние на архитектуру

- `features/delete-message`: действие пользователя, публичный API через `index.ts`.
- `entities/message` и `entities/settings`: удаление и флаг звука.
- `features/notifications`: отмена уведомления.
- `pages/chat-room` и `pages/scheduled`: диалоги и обновление UI остаются на экранах.

## Альтернативы

- Оставить копии на экранах: легко разъехаться по звуку или отмене уведомления.
- Поднять действие в `entities`: сущность не должна знать про звук и уведомления.

## Оценка сложности

Низкая. Риск — забыть обновление списка на одном из экранов. Покрытие: unit-тест с моками базы, уведомления и звука.
