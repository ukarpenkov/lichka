# Иконки выхода из Future: стрелка вверх и часы влево

**Статус:** implemented

## Название фичи

`future-peek-exit-icons` — при жесте возврата из режима **Будущее** в историю чата якорь peek должен зеркалить вход: сверху стрелка **вверх**, снизу часы со стрелкой **влево**.

## Описание проблемы

Режим Future открывается overscroll-жестом из истории чата. На пороге появляется якорь: **часы + стрелка вправо** (вперёд во времени) и вертикальная черта со **стрелкой вниз**.

Выход из Future — тот же паттерн, но в обратную сторону (тянем список вниз у верхнего края). Сейчас `FuturePeekOverlay` для `direction="exit"` **переиспользует входной визуал**:

- рядом с часами — `ChevronRight` (вправо);
- на линии — `ChevronRight` повёрнутый на 90° (вниз);
- кластер якоря прижат к верху: часы сверху, черта вниз.

На экране Future это читается как «ещё глубже вперёд», хотя жест возвращает **назад в чат**. Нужны зеркальные знаки: назад во времени (влево) и направление к истории (вверх).

Жест оси Y (pull down), не горизонтальный свайп табов: на `ChatRoom` pager главных табов выключен.

## Предлагаемое решение

В `features/chat-future-peek` развести якорь по `PeekDirection`:

| Направление | Жест | Иконки времени | Гайд |
|-------------|------|----------------|------|
| `enter` (история → Future) | pull up у низа ленты | часы + стрелка **вправо** сверху кластера | черта **вниз** (без изменений) |
| `exit` (Future → история) | pull down у верха ленты | часы + стрелка **влево** **снизу** кластера | черта **вверх** (наконечник у шапки) |

Технически:

- Рядом с часами: `ChevronRight` на enter, `ChevronLeft` на exit.
- Наконечник гайда: поворот `ChevronRight` на `90deg` (вниз) vs `-90deg` (вверх) — без новой pixel-иконки, как сейчас.
- На exit порядок в кластере обратный: сначала гайд (стрелка вверх + линия), затем часы со стрелкой влево. Якорь остаётся под шапкой (`anchorExit`).

Порог, haptic, rubber-band и сами жесты не меняются.

## Влияние на архитектуру (FSD)

| Слой | Изменение |
|------|-----------|
| `features/chat-future-peek` | `FuturePeekOverlay`: раздельный enter/exit визуал, тесты |
| `pages` / `entities` / `shared` / `app` | без изменений (иконки `ChevronLeft` / `ChevronRight` уже в `shared/ui/pixel`) |

Зависимости только вниз. Public API слайса не расширяется.

## Альтернативы

| Вариант | Почему не выбран |
|---------|------------------|
| Оставить один `PeekDownGuide` для обоих направлений | Ломает метафору «назад из будущего» |
| Новые pixel-иконки ChevronUp / ArrowBack | Лишний набор; поворот существующего шеврона уже принят в проекте |
| Горизонтальный свайп Future → чат | На ChatRoom таб-пейджер выключен; выход — вертикальный overscroll, как `futureExitA11y` |

## Оценка сложности

Низкая: правка раскладки оверлея + RTL-тесты на направление иконок. Риск: на коротком empty Future линия может пересечь «Nothing scheduled yet» — слот гайда exit (160px) уже ограничивает высоту, как сейчас.
