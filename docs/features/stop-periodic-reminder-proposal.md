# Остановка периодического напоминания из чата

**Статус:** implemented — поведение запрошено пользователем и реализовано.

## Название фичи

«Остановить напоминание» в меню сработавшего периодического сообщения.

## Описание проблемы

Повторы можно удалить вместе с сообщением, но нельзя остановить их, сохранив последнее срабатывание в истории чата.

## Предлагаемое решение

Добавить действие в меню долгого нажатия только для активного периодического сообщения, уже появившегося в истории. Преобразовать существующий шаблон в отключённое обычное напоминание (`reminder`): очистить интервал, сохранить ID, текст и вложение, установить время последнего срабатывания в `scheduledAt`, `createdAt` и `updatedAt`. Последнее срабатывание пересчитать на момент остановки по той же формуле, что использует история чата. Отменить нативное расписание и обновить историю, будущие события и виджет. Значок повтора заменится обычным значком напоминания. Нового срабатывания при остановке не создавать.

## Влияние на архитектуру

- `entities/message`: преобразование и общий расчёт последнего срабатывания через публичный API.
- `features/notifications`: действие остановки и отмена уведомления внутри существующего слайса.
- `pages/chat-room`: пункт меню, вызов действия и обновление экрана.
- `shared/config/locale`: подписи для всех поддерживаемых языков.

## Альтернативы

- Только `enabled = false`: сообщение исчезнет, поскольку история исключает периодические шаблоны.
- Удалить шаблон и создать сообщение: лишняя смена ID и риск удаления вложения.
- Сохранить как `simple`: теряется семантика сработавшего уведомления. Выбрано `reminder` без активного расписания.

## Оценка сложности

Низкая, около 1–2 часов. Риски: синтетический ID сообщения, устаревшее время открытого меню, случайное повторное планирование и потеря вложения. Проверки: преобразование и защитные условия, отмена по ID шаблона, видимость пункта меню, защита от случайного нажатия и отображение обычного напоминания.
