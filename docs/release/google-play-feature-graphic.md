# Google Play — Feature graphic

Store listing field: **Feature graphic** (Картинка для описания)

## Requirements

- Format: PNG or JPEG
- Size: **1024 × 500** px
- File size: ≤ **15 MB**
- Used to promote the app in Play Store surfaces

## File to upload

```
docs/release/icons/play-store-feature-1024x500.png
```

| Property | Value |
|----------|-------|
| Resolution | 1024 × 500 |
| Format | PNG |
| Size | ~50 KB |
| Theme | `green-on-black` (`#000000` / `#39FF14`) |
| Type | Press Start 2P + JetBrains Mono |
| Motif | Terminal session, scanlines, pixel grid, feather mark |

## Notes

- Style matches in-app terminal / pixel language (`docs/design/lichka-design-system.md`).
