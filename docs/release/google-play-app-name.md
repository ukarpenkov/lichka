# Google Play — App name

Store listing field: **App name**  
This name will be shown on Google Play.  
**Limit:** 30 characters max.

## Text

```
Lichka: Chats Reminders Alarms
```

**Length:** 30 characters.

## Why this form

- `Lichka: Self Chats & Reminders` = 30 символов — **Alarms** уже не влезает.
- `Lichka: Chats Reminders Alarms` держит бренд + три поисковых слова (chats / reminders / alarms) в лимите.
- Смысл «self chats» остаётся в short/full description.

Matches brand; in-app launcher label can stay `Lichka`.
